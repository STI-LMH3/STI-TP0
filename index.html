📖 Cours : La Balise Hypertexte <a> et ses Propriétés

1. La Balise HTML <a> et ses Attributs

La balise <a> permet d'insérer un lien hypertexte. Ses attributs essentiels sont :


Attribut Détails, Description & Exemples HTML
href="..." Indique l'URL ou le chemin du fichier cible.
Exemple : <a href="Contact.html">Contact</a>
target="..." Définit le lieu d'affichage du lien :
• _blank : Ouvre dans un nouvel onglet.
  Ex : <a href="Contact.html" target="_blank">Contact</a>
• _self : Ouvre dans le même onglet (par défaut).
  Ex : <a href="Index.html" target="_self">Accueil</a>
• _parent : Cadre parent.
  Ex : <a href="Page.html" target="_parent">Parent</a>
• _top : Pleine fenêtre.
  Ex : <a href="Page.html" target="_top">Pleine Fenêtre</a>
title="..." Affiche une info-bulle explicative au survol du pointeur de la souris.
Exemple : <a href="Info.html" title="Info-bulle">Lien</a>

2. Propriétés CSS & Pseudo-Classes d'un Lien

Pour modifier l'apparence et les différents états du lien :


Propriété / Pseudo-classe Rôle en CSS
display: inline; Comportement par défaut : le lien reste dans le flux du texte.
display: block; Transforme le lien en bloc occupant toute la largeur (100%).
display: inline-block; Lien sur la même ligne mais permettant de régler width, height, padding, margin.
display: none; Masque complètement le lien sur la page.
text-decoration Sert à enlever le soulignement avec none ou à l'ajouter avec underline.
a:link Applique un style aux liens non encore visités par l'utilisateur.
a:visited Applique un style aux liens déjà visités dans le navigateur.
a:hover Applique un style lorsque la souris survole le lien.
a:active Applique un style au moment exact où l'utilisateur clique.
a:focus Applique un style lorsque le lien reçoit le focus (navigation clavier).



Exemple HTML & CSS <!-- Exemples HTML pour target -->
<a href="Contact.html" target="_blank" title="Envoyer un message">Contact (Onglet)</a>
<a href="Index.html" target="_self">Accueil (Même page)</a>

/* Style CSS pour la balise a et ses différents états */
a { display: inline-block; text-decoration: none; }
a:link { color: #0288d1; }
a:visited { color: #8e44ad; }
a:hover { color: #d32f2f; text-decoration: underline; }
a:active { color: #f39c12; }
a:focus { outline: 2px solid #2ecc71; }

📚 Cours : Les Listes HTML (<ul>, <ol>) & Propriétés CSS

1. Balises HTML de Listes

En HTML, les éléments d'une liste sont encadrés par <li> (List Item) :

  • <ul> (Unordered List) : Liste non ordonnée à puces.
  • <ol> (Ordered List) : Liste ordonnée numérotée. Attributs HTML : start="5" (début de numérotation), reversed (ordre inverse), et type="A|a|I|i|1".

2. Propriétés CSS des Listes

Propriété CSS Valeurs & Explications
list-style-type Puces <ul> : disc (● par défaut), circle (○ cercle vide), square (■ carré), none (supprime les puces).
Numérotation <ol> : decimal (1, 2, 3), decimal-leading-zero (01, 02), lower-alpha (a, b), upper-alpha (A, B), lower-roman (i, ii), upper-roman (I, II).
list-style-position • outside : Puce à l'extérieur du bloc de texte (par défaut).
• inside : Puce intégrée à l'intérieur du bloc de texte.
list-style-image url('icone.png') : Permet de remplacer la puce par une image personnalisée.
list-style Raccourci CSS : list-style: square inside url('bullet.png');

Code HTML principal appliquant la structure et faisant appel à style.css :




Index.html <!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8" />
  <title>Accueil - EasyTravel</title>
  <link rel="stylesheet" href="style.css" />
</head>
<body>
  <header>
    <a href="Index.html"><img src="Images/Logo.png" alt="Logo" /></a>
    <img src="Images/Baniere.png" alt="Bannière" />
  </header>
  <nav>
    <a href="Index.html" target="_self">Accueil</a>
    <a href="Contact.html" target="_self">Contact</a>
    <a href="Forum.html" target="_self">Forum</a>
  </nav>
  <main>
    <h1>Bienvenue chez l'agence EasyTravel</h1>
    <p>Lorem ipsum dolor sit amet...</p>
  </main>
  <aside>
    <h3>Archive des prestations</h3>
    <!-- Liste non ordonnée avec style square -->
    <ul class="menu-puces">
      <li>Archive2021
        <!-- Liste ordonnée avec attribut start -->
        <ol start="10" class="archives-list">
          <li><a href="Archives/Arch11-2021.html" target="_blank">Novembre 2021</a></li>
          <li><a href="Archives/Arch10-2021.html" target="_blank">Octobre 2021</a></li>
        </ol>
      </li>
      <li>Archive2022 (non encore prêt)</li>
    </ul>
  </aside>
  <footer>© 2026 EasyTravel - Tous droits réservés</footer>
</body>
</html>
